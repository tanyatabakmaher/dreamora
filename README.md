# Dreamora

אפליקציית מעקב חיסכון לפי מטרות (עברית, RTL). קובץ אחד: `index.html`.

- התחברות והנתונים: Supabase (Auth + טבלת `goals` עם RLS), ראו `supabase/001_goals.sql`.
- פרסום: GitHub Pages מתוך הענף הראשי.
- האפליקציה היא כלי מעקב בלבד ואינה ייעוץ השקעות.

האתר: https://tanyatabakmaher.github.io/dreamora/
